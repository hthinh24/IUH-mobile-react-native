## How the link works

- The URL defines the file tree once and loads each source file from the public GitHub branch `feat/day-10-bookstore`.
- GitHub is the source of truth. After a task is implemented and committed, reload this exact URL to fetch the latest branch contents.
- Do not replace this query-driven URL with a Snack `/{id}` URL if you expect it to keep tracking GitHub. Saving a Snack creates a saved snapshot and does not automatically sync later GitHub commits.
- This is a regular Expo Snack URL; no EAS project or cloud sandbox is required.
